# Svjetlost Graf - nezvanicni demo

Samostalan Next.js/React/TypeScript koncept za digitalnu stampariju Svjetlost Graf u Dobrinji. Nije narucen niti odobren od vlasnika. Predlozeni vizuelni identitet, ilustracije printera i korica su originalni demo materijal.

## Lokalno

`npm install`, `npm run typecheck`, `npm run build`, `npm run dev`.

Poslovni podaci i grupisanje usluga su u `business.ts`. Kontakt vodi iskljucivo na telefonski poziv; Maps link otvara pretragu naziva i pune adrese, bez tvrdnje o preciznom pinu. Metadata sadrzi `noindex, nofollow`, a `/robots.txt` zabranjuje indeksiranje.

## Prije sluzbene upotrebe vlasnik treba potvrditi

- Tacan i aktuelan popis usluga, posebno graviranje, pecate i vrste uveza.
- Telefon, adresu, precizan Maps pin i radno vrijeme.
- Cijene, rokove, formate, vrste materijala i postupak zaprimanja dokumenata.
- Odobreni naziv, logo, fotografije, tekst, domen i saglasnost za objavu.

Ocjena i recenzije nisu koristene. Sluzbeni cjenovnik i sati nisu prikazani. Podaci firme Svjetlost-BH Print nisu koristeni.
